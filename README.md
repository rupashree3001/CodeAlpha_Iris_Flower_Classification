# Iris Flower Classification

## Project Overview
This project uses Machine Learning to classify Iris flowers into three species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Dataset
The Iris dataset contains 150 samples with:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model

K-Nearest Neighbors (KNN)

## Results

- Accuracy: 100%
- All test samples classified correctly
